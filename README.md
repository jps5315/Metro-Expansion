# Metro-Expansion
This project is a reference application built to assist city planners with a metro city expansion. It collects health records, distances, travel times, and weather condition records and stores them in a PostGIS database that performs coordinate transformations to standardize the CRS. Users place a facility on a map, and the application calculates a gravity score from 0 to 1 that indicates placement suitability using a weighted sum across multiple parameters.
